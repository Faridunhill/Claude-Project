# First-Five Calibration — photo drop

Farid: put each pipe's six photos into its numbered folder. Photos only —
no names, no hints. The blind test is the point.

## The six photos per folder

| Filename | What it shows |
|---|---|
| `left.jpg` | Full pipe, left side |
| `right.jpg` | Full pipe, right side |
| `top.jpg` | Looking down at the bowl rim / chamber |
| `bottom.jpg` | Underside of bowl and shank |
| `stampA.jpg` | Close-up of the shank stamping |
| `stampB.jpg` | Other side of shank or stem logo (optional) |

- Names only need to **start with** the word (`left-1.jpg` is fine).
- **JPEG please, not HEIC** — on iPhone: select the photos → Share →
  save/export as JPEG, or shoot with Settings → Camera → Formats →
  Most Compatible.
- Any resolution; they're resized automatically before analysis.

## How to upload (GitHub website, works on phone or PC)

1. Open **github.com/Faridunhill/Claude-Project** and switch the branch
   selector to `claude/pipe-authentication-system-vh4i3d`.
2. Navigate into `calibration/pipe-01`.
3. **Add file → Upload files**, select that pipe's six photos, press
   **Commit changes**.
4. Repeat for `pipe-02` … `pipe-05`.

(PC is easier — drag and drop all six at once — but the phone browser
works too.)

## What happens next

Claude pulls the photos, runs each pipe **blind** through the cabinet
runner (the same engine the website uses), and reports the five
assessments back for Farid's review. Separately, the same pipes go through
the public passport page to test the customer flow (upload → analysis →
email → PDF). Only after Farid's review do we resume toward the full
200-pipe cabinet.

Keep the answers to yourself until the results are in — write your own
truth list (folder → brand, model, year) privately and compare after.
