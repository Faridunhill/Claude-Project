## LOCKED — style and its roadmap

**v1 — NOW: inked 2D comic.** Heavy black outlines, flat cel shading, briar/brass
palette, still panels with a camera move, burned-in captions, voice-over, **no talking
mouths.** Chosen from Farid's reference, for four reasons that still hold: the ink line
performs the subtraction a model cannot; ink forgives anatomy errors that smooth 3D
punishes; consistency rides on costume signatures rather than the face; and nothing has
to lip-sync, which deletes the avatar, the HeyGen cost and frame-to-frame drift at once.

**★ Farid's own words, 2026-07-31 — this is v1, not the destination:**
> *"It was just an idea we can start with… so yes we will start with this simple now,
> but we will not stop improving, and change it later to complete 3D live."*

**v2 — THE DESTINATION: full 3D.** A modelled, rigged Professor and Assistant in a
modelled workshop, where consistency is guaranteed by construction rather than by style
discipline, the camera can move through a real set, and the anatomy model sections
itself at any plane.

### Why v1 does not become wasted work — the architecture protects the upgrade
The Episode Engine composites **layers resolved from an asset library by id**. It does
not generate finished frames. Therefore:

- Stage 3 asks the library for `prof-explaining-3q`. Whether that id resolves to an ink
  drawing or a render from a 3D rig **is invisible to every other stage.**
- Stages 1, 2, 4, 5, 6, 7 — subject, script, voice, assembly, publishing, ledger — never
  change. **Only the asset files behind the ids change.**
- The scripts, panel lists and published episodes stay valid: an old episode can be
  **re-rendered in v2 style from its saved panel list**, with no rewriting.

**Rule that makes this true and must not be broken: no stage may ever hard-code an image
path. Everything goes through an asset id.** That single discipline is what converts
"we will change it later" from a hope into a scheduled upgrade.

The designer commission is written to serve both: a **character sheet with turnarounds,
expressions and shape rules** is exactly the specification a 3D modeller needs. Buying
the design once feeds v1 this month and v2 whenever Farid calls for it.

### What replaces it — THE EVIDENCE FORMAT (now the default)
A real photograph from our own archive · a slow push · a text card · Farid's voice · the
brand frame. Seven beats, one narrator, no dialogue, **nothing drawn and nothing
commissioned.** `engine/run.mjs` now defaults to `--format evidence`.

**It is not a downgrade. It is the honest form of the same show**, and it always was:
this repo already ruled that facts must be photographed and never drawn (the EVIDENCE vs
KNOWLEDGE rule). The characters only ever carried the *story*. Losing them costs the
story frame; it costs **zero** evidence — which is the part collectors came for.

**Also settled: there is no v1 → v2 upgrade ladder any more.** The ink-now/3D-later plan
existed only to stage the character spend. With no character, the ceiling on quality is
our own photography, which is already good. If 3D ever returns it will be for the
anatomy cutaway alone — an optional prop, not a person, and not a dependency.

### Two script rules this format forced, both honesty rules
1. **A feature is not a mark.** A tapered bit is spoken as *"look at the bit — this one
   is tapered"*, never *"the mark reads…"*.
2. **No straw men.** The "what you will usually be told" beat only appears when the
   cabinet's caveat names a year the real era excludes — i.e. when a wrong belief
   genuinely exists. Otherwise the episode becomes *"here is a clue most people skip"*.
   Inventing a wrong belief in order to correct it would be a small lie.

### The only input left in the whole engine
**One ElevenLabs voice id.** That is the last open field. Everything else runs.
