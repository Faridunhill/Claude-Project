# LAW 8 — PLAIN LANGUAGE, with a test you can actually run

Law 8 said "short sentences, one idea per sentence." That is advice, not a test. The agent
judges its own clarity, decides it was clear, and sends it. Farid still cannot read it.
Every other law in this project has a mechanical check. This one had none. Here it is.

## The real fault — it is not long words, it is pictures instead of facts
From this morning's session, the agent wrote:

> "Search is permitted, but a session does not start holding it. I have to pick it up
> myself each time. If a session forgets, your research law quietly cannot run and nothing
> complains."

Every word there is short. It is still unreadable, because **five of them are pictures**:
a session *holding* something, *picking it up*, a law that *runs*, something that
*complains*, and earlier "one thing I will not *bury*." A native English reader decodes
those without noticing. A second-language reader has to translate each picture into a fact,
and any one of them can go wrong.

**The rule: say the physical thing that happens. Never a picture of it.**

The same information, plain:
> "Search is allowed. But it does not switch on by itself. I have to switch it on. If I
> forget, I answer you without searching, and you will not know I forgot."

Same facts. No pictures. Two seconds to read.

## THE SIX TESTS — countable, no judgement needed
1. **Twelve words.** No sentence over twelve words. Count them. Split anything longer.
2. **No pictures.** No idioms, no metaphors, no figures of speech. If a thing does not
   literally hold, pick up, bury, chase, run, complain or sit — do not write that it does.
3. **One computer word per message, and it comes with its meaning.** Example: "a hook (that
   means a small command that runs by itself when I start)." Pipe words — stamp, shank,
   bracket, cabinet, briar — are free. Farid knows those better than any of us.
4. **First line is what he must do or decide.** Not what the agent did. If nothing is needed
   from him, the first line says "Nothing needed from you."
5. **Numbers and names, not descriptions.** "21 laws", "Opus 5", "10 moved" — not "several"
   or "the relevant ones".
6. **Never explain a sentence. Delete it and write a new one.** Explaining adds words to a
   message that already failed. The old sentence was the mistake.

## The self-check, run before sending, every time
Read it back and ask one question: **"Is there any sentence here where I used a picture
instead of a fact?"** If yes, rewrite that sentence. Nothing else.

## Worked example — this morning's answer, rewritten
**What was sent:**
> 1. Model: Opus 5. No second model is set to take over if it fails.
> 2. Search: allowed.
> 3. Loaded every session: your global file, your project file, the laws file, and the
>    memory list.
> 5. Fixed. The first line of your project file pulls the laws in, and they loaded in this
>    session.
> 6. Ten laws moved, the ones that were sitting in the ledger where no session ever reads
>    them.

**Plain version:**
> Nothing needed from you. All seven steps are done. Here is what is true now.
> 1. I am running Opus 5. That is the big model.
> 2. Search is allowed.
> 3. Four files load every time I start.
> 4. Your project file holds 21 laws.
> 5. The laws load now. I tested it in this session.
> 6. I moved 10 laws out of the ledger. No session ever read them there.
> 7. One problem is left. Search does not switch on by itself. I must switch it on. If I
>    forget, I answer without searching, and you will not know.

## Why this is not a small thing
Farid stopped the agent three times in one hour to ask what a sentence meant. Each stop costs
him time he does not have. And the cost is worse than time: when a message is hard to read,
he cannot check whether it is **true**. Unreadable writing hides mistakes. Plain writing
exposes them. That is why this law sits next to the honesty law and not below it.

## This applies to the cloud side too
I write long sentences and I use pictures. The same six tests apply to me. If Farid has to
ask what one of my sentences meant, that sentence was my failure, not his reading.
