## The two open items that block the most

1. **The Grain Print's error rate** — false-match and false-reject on genuinely
   re-acquired pipes, especially refinished ones. The registry, the logbook and
   the repeat-sales index all rest on it and nobody has measured it. Response §07a.
2. **The cost of external sold-price data** — the honest index requires excluding
   Faridunhill's own sales, which means buying or scraping observations from
   elsewhere. Unpriced. Response §06.2.

Both are measurements, not opinions, and both are LOCAL-side jobs — the archive
and the re-acquired pipes are on Farid's PC, not here.
