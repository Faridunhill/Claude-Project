## 2. THE LAWS THIS ENGINE ENFORCES IN CODE (never weaken one to improve a number)

1. **No source, no episode.** `subject.mjs` / `cabinets-json.mjs` refuse and print it.
2. **No matching photograph, no illustration.** A feature claim may only be illustrated
   by a photograph showing that feature; otherwise the engine prints `SHOT NEEDED`.
   *(Added after Farid caught it showing a saddle stem while saying "tapered".)*
3. **No straw men.** The "what you'll usually be told" beat only appears when the
   cabinet's caveat names a year the real era excludes.
4. **A feature is not a mark.** A tapered bit is never called a stamp.
5. **Determinism.** No `Date.now()`, no `Math.random()`. Same input, same episode.
